# Benefício Social

Plataforma RPA para análise e cadastro de clientes aptos ao benefício social/desconto por baixa renda.

## Objetivo

Demonstrar uma solução corporativa com:

- CRUD de clientes
- Login e autenticação
- Upload de documentos PDF/PNG
- PostgreSQL
- Segurança de credenciais
- Worker RPA em Python
- Execução via subprocess
- Logs estruturados
- Métricas
- Grafana
- Alertas
- Evolução futura com OCR e IA local

## Stack

- Python
- FastAPI
- PostgreSQL
- Angular
- TypeScript
- Docker
- Prometheus
- Grafana
- Loki
- Windows Credential Manager

## Segurança

Este projeto não versiona:

- credenciais
- tokens
- arquivos `.env`
- documentos reais
- PDFs reais
- imagens reais
- logs com dados sensíveis
